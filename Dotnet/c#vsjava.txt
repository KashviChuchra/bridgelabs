Interview Summary (Easy to Remember)
	• Both Java and C# are object-oriented, statically typed, compiled to an intermediate language, and use JIT compilation with automatic garbage collection.
	• Java compiles to Bytecode and runs on the JVM.
	• C# compiles to IL (MSIL/CIL) and runs on the CLR.
	• C# offers more language features such as properties, delegates, events, LINQ, extension methods, structs, operator overloading, async/await, nullable value types, and reified generics.
	• Java emphasizes portability and has a long-established enterprise ecosystem with frameworks like Spring Boot. It also supports checked exceptions and uses type erasure for generics.
	• .NET/C# is a strong choice for modern web APIs, cloud applications, Windows development, and Unity game development, while Java remains dominant in enterprise backends, financial systems, and many large-scale server applications.
